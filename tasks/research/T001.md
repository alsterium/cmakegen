## Decisions

### Toolchain

| Component | Minimum |
|---|---|
| CMake | 3.28.0 |
| CMake Presets schema | 8 |
| GCC | 12.1 |
| Clang + libc++ | 16.0 + 16.0 |
| MSVC | Visual Studio 2022 17.6 |

The C++23 requirement is retained. `std::expected` is a required library
facility and will be compile-checked by the bootstrap configure step. The MVP
does not depend on `std::format` or fmt.

### Dependencies

| Role | Version | Package name | Imported target | Bootstrap |
|---|---:|---|---|---|
| YAML parser | 0.8.0 | `yaml-cpp` | `yaml-cpp::yaml-cpp` | yes |
| JSON serializer | 3.12.0 | `nlohmann_json` | `nlohmann_json::nlohmann_json` | yes |
| CLI parser | 2.6.2 | `CLI11` | `CLI11::CLI11` | yes |
| Test framework | 3.15.3 | `Catch2` | `Catch2::Catch2WithMain` | no |

CLI11 is the selected CLI parser. Catch2 is normal-build/test-only because the
bootstrap must remain capable of building only a functional generator.

### Acquisition strategy

The project schema remains package-manager agnostic: it emits `find_package()`
and links imported targets, but does not accept source URLs or revisions.

`cmake/dependencies.cmake` is a manually maintained, user-owned file. It is
included before generated package lookups and follows this policy:

1. Prefer a compatible package already provided by CMake, a system install, or
   a package-manager toolchain.
2. If absent, use `FetchContent` to download the selected upstream release
   archive.
3. Pin each archive URL with `URL_HASH SHA256=<digest>`; do not fetch branches
   or floating tags.
4. Use `OVERRIDE_FIND_PACKAGE` when declaring content so later generated
   `find_package()` calls resolve to the fetched package.

The actual archive URLs and SHA-256 values are introduced with
`cmake/dependencies.cmake` in T002 and are verified against each upstream
release at that time. Upgrades must modify the version, URL, and hash together.

### Hashing

Generated-file manifest hashing uses an in-tree SHA-256 implementation. This
avoids adding OpenSSL or another crypto package to the bootstrap graph. T011
will choose a small audited permissively licensed implementation, retain its
license notice, and test standard SHA-256 vectors.
