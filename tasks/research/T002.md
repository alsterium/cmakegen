# T002 Research — Bootstrap dependency archive verification

- Date: 2026-08-08
- Scope: Verify the release-archive URLs and SHA-256 pins used by the
  hand-maintained bootstrap dependency hook.

## Sources and verification

The selected versions and exported targets come from T001. The following
release tags were checked against their upstream GitHub releases, then their
canonical `archive/refs/tags/...tar.gz` bytes were downloaded over HTTPS and
hashed locally with `shasum -a 256`:

| Dependency | Tag archive | SHA-256 |
|---|---|---|
| yaml-cpp | `jbeder/yaml-cpp` `0.8.0` | `fbe74bbdcee21d656715688706da3c8becfd946d92cd44705cc6098bb23b3a16` |
| CLI11 | `CLIUtils/CLI11` `v2.6.2` | `c6ea6b2e5608b3ea8617999bd5f47420c71b2ebdb8dc4767c1034d1da5785711` |
| nlohmann_json | `nlohmann/json` `v3.12.0` | `4b92eb0c06d10683f7447ce9406cb97cd4b453be18d7279320f7b2f025c10187` |
| Catch2 | `catchorg/Catch2` `v3.15.3` | `b0299ae552918220a7a6e21e7de5b714777f4e8c883fb70c4bb23fe01df8c6e3` |

The unpacked upstream CMake projects were also inspected to verify that the
fallback provides the imported targets selected in T001. The fallback only
runs if a compatible `find_package(... CONFIG QUIET)` does not already provide
the target. `OVERRIDE_FIND_PACKAGE` keeps later normal-build package lookups
consistent with the fetched content.
