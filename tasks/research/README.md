# Research Notes

Create `TNNN.md` here only when a task depends on information that may have
changed, such as upstream specifications, library targets, APIs, or platform
behavior.

Each note should record:

- the question being resolved
- retrieval date
- primary sources and relevant versions
- conclusion and implementation impact
- remaining uncertainty

Research notes inform decisions; normative product behavior still belongs in
the relevant existing file under `docs/`.
