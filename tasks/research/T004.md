# T004 Research — yaml-cpp parser interface

- Date: 2026-08-08
- Scope: yaml-cpp 0.8.0 APIs needed to preserve parser diagnostics and source
  locations in the raw schema layer.

## Primary source consulted

- [yaml-cpp 0.8.0 public headers](https://github.com/jbeder/yaml-cpp/tree/0.8.0/include/yaml-cpp)
  document the pinned release's public `Node`, `Mark`, parsing, and exception
  interfaces. The locally acquired source was inspected against that release.

## Decisions

- Use `YAML::Load` only on in-memory YAML text in the raw parser. File reads
  remain outside this layer, so failed parsing cannot mutate the filesystem.
- Convert `YAML::Mark` from yaml-cpp's zero-based line and column values to the
  project diagnostic model's one-based `SourceLocation` values.
- Validate scalar kinds before conversion and translate yaml-cpp parse or
  conversion failures into `DiagnosticSet`; yaml-cpp exceptions do not cross
  the parser API boundary.
