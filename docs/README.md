# cmakegen — Implementation Documentation

`cmakegen` is a declarative project generator for modern CMake, implemented entirely in modern C++.

The project is intentionally designed to become **self-hosting**:

> `cmakegen` itself is described by `project.yml`, and its normal CMake files are generated by `cmakegen`.

The only exception is the initial bootstrap path required before a working `cmakegen` binary exists.

```text
project.yml
   │
   ├──────────────┐
   │              │
   │ bootstrap    │ self-hosted
   ▼              ▼
bootstrap/     cmakegen generate
CMakeLists.txt     │
   │               ▼
   └────────> CMakeLists.txt
              CMakePresets.json
              cmake/cmakegen.generated.cmake
```

## Primary implementation constraints

- Implementation language: **C++23**
- Build system: CMake
- Project source of truth: `project.yml`
- Generated CMake is checked into the repository
- Generated output must be reproducible
- CI must verify that checked-in generated CMake matches `project.yml`
- No production implementation in Rust, Swift, Python, Go, or another language
- Small scripts may exist only for repository tooling if unavoidable; they must not be required to build or run cmakegen

## MVP

The MVP supports:

- C and C++
- executables
- static/shared/interface libraries
- source directory expansion
- include directories
- compile definitions
- compile options
- target-to-target dependencies
- `find_package`
- Debug/Release presets
- macOS/Linux/Windows conditions
- deterministic generation
- `generate`, `validate`, `dump`, `graph`, and `clean`
- building cmakegen itself from `project.yml`
- bootstrapping cmakegen from a minimal checked-in bootstrap CMake project

## Design principle

`cmakegen` is not “CMake syntax in YAML”.

It is an opinionated C/C++ project model that generates readable Modern CMake, while still allowing custom user-owned `.cmake` files to be included.
